How to Print

1. Press Ctrl + P (or Cmd + P on Mac)
2. Set paper size to Letter (8.5 x 11)
3. Set orientation to Landscape
4. Set margins to Default (the cards already account for printer margins)
5. Set scale to 100% (not "fit to page")
6. Check "Background graphics" — critical!
7. Save as PDF and upload to FedEx
8. Cut into 3 equal vertical strips with your paper cutter
